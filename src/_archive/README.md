# Archived experiments

Earlier iterations of this site, kept for reference only. They are **excluded
from `tsconfig`, not imported by the app, and not part of the bundle**.

- `game/` — third-person 3D exploration world (Three.js)
- `room/` — first-person "memory room" (Three.js)

> These depend on `three`, which is **no longer a project dependency**.
> To revive an experiment, reinstall it first: `bun add three`.
